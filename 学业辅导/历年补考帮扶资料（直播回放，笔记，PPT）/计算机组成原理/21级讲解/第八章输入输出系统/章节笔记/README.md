<ul>
<li>章节概述
本章内容看起来比较多，但考点主要是程序查询、程序中断和DMA三种控制方式的处理过程以及中断屏蔽字，硬件电路的部分一般不会出题。考察方式偏向于记忆，题型以选择填空简答为主，即使涉及计算，也不会很复杂。</li>
<li>知识点整理
<ul>
<li>程序查询方式：主要要理解传送数据的基本流程</li>
<li>程序中断方式：中断服务程序的流程（4步）、中断向量地址、CPU响应中断的条件和时间、中断隐指令</li>
<li>DMA：DMA方式传送数据不经过CPU、DMA与主存交换数据的三种方式、中断服务程序进行后处理</li>
<li>三种控制方式在速度、CPU与外设是串行还是并行工作上的对比</li>
<li>中断屏蔽字的书写</li>
<li>统一编址</li>
<li>接口电路，其中程序中断方式的接口电路较另外两种方式的接口更加重要</li>
</ul>
</li>
</ul>
